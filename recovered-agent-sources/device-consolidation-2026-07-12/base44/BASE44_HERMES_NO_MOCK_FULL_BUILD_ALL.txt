# All 9 Pages — No Mock Acceptance Criteria

- Shows real OwnerBrief when imported/generated/synced.
- Shows counts from real entity tables only.
- No fake cards.
- Has buttons: Import Brief JSON, Sync from Hermes Bridge, Create Manual Brief.

2. JARVIS Mode Router
- Form: intent, risk class, surface.
- Deterministic local routing helper generates JarvisModeRoute from form input.
- Persist route as real record.
- Generate TaskPacket from route and persist it.
- No fake prior routes.

3. Memory Tree Browser
- Shows real MemoryNode tree/list only.
- Filters by namespace, confidence, freshness, approvalState, contradictionState.
- Detail panel supports approve/reject/supersede/contest.
- Import JSON supports array of MemoryNode objects.

4. Natural Language Coding Packetizer
- Form: plain-English task, repoRoot, riskClass, allowedFiles, forbiddenFiles, nonGoals.
- Generates real TaskPacket record.
- Branch name generated deterministically from task title + date.
- Can send packet to Verification Gate Console by creating pending gate rows.

5. Verification Gate Console
- Select real TaskPacket.
- Shows exactly 8 gate cards for that packet.
- If no gate rows exist, user can initialize pending gate rows.
- Overall result computed from actual gate statuses.
- No fake pass/fail statuses.

6. Avatar / Companion Presence Console
- Shows real AvatarState records only.
- Lets owner create/edit avatar name, style, size mode.
- Supports animation beat timeline editor.
- Empty state says no avatar state synced/created yet.

7. Android Action Broker Console
- Form: natural-language command.
- Creates AndroidActionContract with ownerAuthorized=true.
- Computes highConsequence from command keywords: send, post, buy, delete, password, share private data, transfer, submit.
- executionMode rules:
  - missingCapabilities non-empty => blocked_missing_capability
  - highConsequence true => execute_with_pause_point
  - otherwise => direct_execute
- Does not execute Android actions inside Base44.
- Can send to bridge only if bridge configured.

8. Research Vault
- Shows real ResearchArtifact records only.
- Import/edit/filter by status/topic/confidence.
- Must include fields for license notes and implementation relevance.
- No preseeded research cards unless imported by owner.

9. Settings / Authority
- Owner authorization mode visible and editable.
- Bridge URL and bridge enabled controls.
- High-consequence pause action list editable.
- Allowed/blocked packages editable.
- Disclaimer: local/private testing; no secrets in Base44; real Android execution lives in Hermes Android app.
- Provides Export All Data and Import All Data actions if Base44 supports it.
# Hermes Local Bridge API Contract — Real Sync Only

Build Base44 adapter functions around this contract, but do not call them until SettingsAuthority.bridgeEnabled is true and hermesBridgeUrl is non-empty.

Base URL example:
http://127.0.0.1:8765
or Android/local network address configured by owner.

Endpoints to support later:
GET /health
Response:
{ "ok": true, "runtime": "hermes", "version": "...", "jarvis_prime": true }

GET /owner-brief
Response:
OwnerBrief JSON object or null.

GET /memory-nodes
Response:
{ "items": [MemoryNode objects] }

GET /task-packets
Response:
{ "items": [TaskPacket objects] }

POST /task-packets
Body:
TaskPacket object
Response:
{ "ok": true, "id": "...", "status": "accepted" }

GET /verification-gates?taskPacketId=...
Response:
{ "items": [VerificationGateResult objects] }

GET /avatar-state
Response:
AvatarState JSON object or null.

POST /android-action-contracts
Body:
AndroidActionContract object
Response:
{ "ok": true, "id": "...", "status": "accepted|blocked|completed", "message": "..." }

GET /research-artifacts
Response:
{ "items": [ResearchArtifact objects] }

Adapter behavior:
- Missing bridge URL => bridge_not_configured.
- bridgeEnabled false => bridge_disabled.
- HTTP/network failure => bridge_unreachable.
- Non-2xx response => bridge_error with status code.
- Empty response => show empty state.
- Never create fake fallback records.

Security:
- Do not store API keys/secrets in Base44.
- If bridge requires auth later, use local one-time pairing flow in Hermes, not hardcoded tokens.
