Components

Buttons

Four button variants from the Singularity language. White is the hero: the primary is the single core-fill control; everything else holds back in tonal value. No glow, no drop shadows, round caps.

Primary

Core fill, void text — the single bright control on a view. Use it once.

DEFAULT
HOVER Lifts to a brighter cool-white (#f2fbff).
DISABLED
FOCUS RING 2px matte cyan ring (--ring-1), 2px offset.

Secondary

1px hairline edge + signal text. Tonal fill appears only on interaction.

DEFAULT
HOVER Fills with raised void tone (--void-2).
DISABLED
FOCUS RING Same 2px cyan ring on keyboard focus.

Ghost

Transparent, dim signal text. The quietest control — lifts toward signal on interaction.

DEFAULT
HOVER Text brightens to --signal over --void-2.
DISABLED
FOCUS RING Cyan focus ring even when fill is transparent.

Danger

Danger text + danger border. UI status color only — tinted fill on interaction, never neon.

DEFAULT
HOVER Fills with a 12% danger tint.
DISABLED
FOCUS RING Focus stays cyan; danger lives in text + edge.
