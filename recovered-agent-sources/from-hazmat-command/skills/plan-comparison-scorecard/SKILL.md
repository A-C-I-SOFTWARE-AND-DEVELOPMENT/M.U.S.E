# plan-comparison-scorecard

## When to use

Council Mode step 5. The multi-plan set exists in
`03-options-or-council-plans.md`. The synthesized master plan has
not yet been authored.

## Inputs

- `03-options-or-council-plans.md` with N completed plans.
- `01-evidence-bundle.md` (every scoring rationale traces back).
- `00-mission-brief.md` (success criteria, non-negotiables, scope).
- `02-risk-classification.md`.

## Method

1. Copy `docs/templates/plan-comparison-matrix-template.md` to the
   run folder (supplement to `03-options-or-council-plans.md`).
2. Confirm independence — you did not author any plan, and you
   will not author `04-synthesized-plan.md` or `05-red-team-review.md`.
3. Score each plan 1–10 on each of the 10 criteria (Strategic
   clarity, Market leadership potential, User value,
   Differentiation, Evidence grounding, Technical feasibility,
   Scope discipline, Risk management, Commercial credibility,
   Long-term extensibility). Each score has an extracted rationale.
4. Populate the surviving-ideas table — each carries the source
   plan(s) and the evidence item that supports it.
5. Populate the rejected-ideas table — each carries a citation
   (evidence item or repo path) for why it was rejected.
6. List assumptions needing proof, contradictions with repo
   reality, scope concerns, execution concerns, and the most-cited
   buyer / engineer / compliance objection.
7. Write a one-paragraph recommendation to the synthesizer naming
   the strongest surviving ideas, the most important rejected
   ideas to preserve as warnings, and the unresolved owner choices
   to surface.
8. Sign the Scorer attestation checklist at the bottom of the
   template.

## Output

Scorecard appended to or supplementing
`03-options-or-council-plans.md`. The synthesizer reads this before
producing `04-synthesized-plan.md`.

## Anti-patterns

- Scoring all plans 7s and 8s without divergent strengths.
- Naming a winning plan (Council Mode synthesizes, it does not
  pick).
- Rejecting ideas without citing evidence.
- A "scorer" who also authored a plan or who will also synthesize
  / red-team.
- Recommending the synthesizer adopt a plan wholesale.
