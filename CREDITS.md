# Credits & heritage — with gratitude

MUSE (Multi-Use Synaptic Entity) is one mind over a synaptic substrate. None of
it would exist without the open work it stands on. This page keeps that
acknowledgement explicit and humble. Nothing here is erased from the license —
see [`LICENSE`](LICENSE).

## Foundations

- **[Nous Research](https://nousresearch.com) — the Hermes agent base (MIT).**
  MUSE grows directly from Hermes; the agent core, gateway, and much of the
  runtime are its lineage. "Hermes" lives on inside MUSE as the name of its
  **synaptic substrate** (the gateway, routing, and model pathways) and in the
  code namespace (`hermes_cli/`) — a substrate, not a brand.
- **[A-C-I Software and Development](https://github.com/A-C-I-SOFTWARE-AND-DEVELOPMENT)**
  — develops and maintains MUSE.

## Concepts (no code copied)

- **[OpenHuman / tinyhumans.ai](https://github.com/tinyhumansai/openhuman)** (GPL-3.0)
  — the local-first voice + embodiment emphasis is a *concept* inspiration only.
  MUSE's implementation is original, MIT-licensed work; no OpenHuman code was copied.

## Capability — the open-weight model communities

MUSE routes work to open models it does not train. With thanks to the teams
behind **DeepSeek**, **Z.ai / Zhipu (GLM)**, **Moonshot AI (Kimi)**, **MiniMax**,
**Alibaba (Qwen / Qwen-VL / Qwen-Omni / embeddings)**, **Google DeepMind (Gemma)**,
**Mistral (Devstral)**, **OpenAI (gpt-oss open weights)**, and **BAAI (BGE)** —
and to the benchmark and leaderboard maintainers whose snapshots we cite in
[`docs/ai-intelligence/`](docs/ai-intelligence/) (SWE-bench, LiveCodeBench,
Terminal-Bench, AIME, MATH-500, MTEB, MMEB, and the aggregators listed there).

## Worker lanes & tools

Gratitude to the maintainers of the official agent CLIs MUSE delegates to as
worker lanes — **Claude Code** (Anthropic) and **Codex** (OpenAI) — and to the
broader open-source agent and skills ecosystem (the [agentskills.io](https://agentskills.io)
