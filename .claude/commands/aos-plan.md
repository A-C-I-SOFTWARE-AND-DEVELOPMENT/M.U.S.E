# AOS Plan Command

Use this command to turn an idea into a structured implementation plan.

## Process

1. Define the mission brief.
2. Build the evidence bundle.
3. Generate at least two candidate plans.
4. Compare plans using a scorecard.
5. Review the preferred plan with the council agents.
6. Revise the plan based on review findings.
7. Convert the plan into build phases.
8. Define acceptance criteria and validation commands.

## Output

- Mission brief
- Evidence reviewed
- Candidate plans
- Scorecard
- Final recommended plan
- Build phases
- Acceptance criteria
- Validation commands
- Open blockers
