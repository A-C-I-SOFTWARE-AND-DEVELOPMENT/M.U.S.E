# AOS Audit Command

Use this command when auditing Hermes, an app repo, an agent system, a launch plan, or a product architecture.

## Process

1. Read `CLAUDE.md` and `AGENTS.md`.
2. Read the AOS reference docs under `docs/context/` and `docs/governance/`.
3. Use `evidence-architect` to verify what is actually installed.
4. Use `principal-systems-architect` for architecture review.
5. Use `product-experience-architect` for workflow and demo readiness.
6. Use `assurance-risk-director` for risk, testing, and release gates.
7. Use `contrarian-reviewer` for assumption review.
8. Use `delivery-scope-controller` to convert recommendations into phases.

## Output

- Verdict
- Installed evidence
- Missing evidence
- Architecture review
- Product review
- Risk review
- Recommended fixes
- Exact implementation checklist
- Validation commands
