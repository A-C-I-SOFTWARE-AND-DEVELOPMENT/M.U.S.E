# AOS Council Skill

Use this skill when the user asks for a deep audit, master plan, launch plan, repo-readiness review, agent system, product strategy, or implementation plan.

## Workflow

1. Clarify the mission only when blocked.
2. Gather evidence from files, docs, logs, tests, and user-provided context.
3. Generate more than one candidate approach.
4. Review the options through specialist perspectives.
5. Compare options with a scorecard.
6. Challenge the preferred plan for weak assumptions.
7. Produce a revised final plan.
8. Convert the plan into phased implementation tasks.
9. Provide acceptance criteria and validation commands.
10. End with rollback notes and remaining blockers.

## Specialist Perspectives

- Council Director
- Evidence Architect
- Systems Architect
- Product Experience Architect
- Commercial Strategist
- Assurance Reviewer
- Delivery Scope Controller
- Contrarian Reviewer
- Coding Dispatch Governor
