# Revised AOS Agent System

## Revised folder structure

- `runnable-agents/` — small active council and runnable decision agents.
- `specialists/` — on-demand domain specialist definitions.
- `skills/` — super-specialist procedures and skill inventory.
- `workers/` — execution worker templates.
- `personas/` — tone and perspective overlays.
- `product-roles/` — business ownership viewpoints.
- `archive/recovered-sources/` — pointers to preserved recovered sources.
- `operating-registry/` — smaller verified registry and schema.
- `slack/` — Slack team usage rules.
- `migration/` — migration and first PR plans.
- `scripts/` — verification tools.

## Revised registry schema

The verified schema is JSON and centered on these top-level sections:
- `policies`
- `active_council`
- `domain_specialists`
- `super_specialist_skills`
- `worker_templates`
- `separated_collections`
- `source_of_truth`
