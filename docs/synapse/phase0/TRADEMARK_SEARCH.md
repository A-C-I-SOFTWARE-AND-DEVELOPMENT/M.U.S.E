# Task 0.4 — Name & Trademark Search: "SYNAPSE"

**Project:** SYNAPSE — A M.U.S.E. Game · **Status:** SEARCH COMPLETE — TITLE AT RISK · **Date:** 2026-06-10
**Owner:** Jeremiah Echerd, A-C-I Software & Development
**Authority:** master plan Task 0.4 / §14 decision 1. This is a preliminary knock-out search to brief the $300 IP consult (§8.5); it is not legal advice and does not replace a professional clearance search.

## Executive verdict

**The working title "SYNAPSE" is NOT clear for use as a shipped game title.**
Both backup names from the master plan (**Synaptic Hunters**, **MUSE: Substrate**) returned **no conflicting game titles or marks** in this search. Recommendation in §4 below. "SYNAPSE" remains safe as the **internal codename and repo name** (no commerce, no consumer-facing use).

## 1. Direct conflicts found (video game goods/services)

| Mark / title | Holder | Evidence | Severity |
|---|---|---|---|
| **SYNAPSE** (video game, 2023, PSVR2) | **nDreams Limited** — "SYNAPSE and the Synapse logo are either registered trademarks or trademarks of nDreams Limited" (their own legal line) | [PlayStation page](https://www.playstation.com/en-us/games/synapse/), [nDreams](https://ndreams.com/games/synapse/), [Wikipedia](https://en.wikipedia.org/wiki/Synapse_(video_game)) | **BLOCKING** — identical mark, identical goods class (video games), recent and actively marketed |
| Synapse Chronicles | CORPUSWORKS (claims TM on title + logo) | [Steam page](https://store.steampowered.com/app/4352970/Synapse_Chronicles/) | High — composite mark in games |
| Frozen Synapse (franchise, 2011–) | Mode 7 Games | [Steam page](https://store.steampowered.com/app/98200/Frozen_Synapse/) | Medium — long-standing composite mark |
| Synapse: Lockdown | (Steam developer) | [Steam page](https://store.steampowered.com/app/2511300/Synapse_Lockdown/) | Medium — composite, same storefront |
| A Tale of Synapse: The Chaos Theories | Souris-lab | [Steam page](https://store.steampowered.com/app/1890810/A_Tale_of_Synapse__The_Chaos_Theories/) | Low–medium — tagged Creature Collector, our exact genre |
| Razer Synapse | Razer Inc. | Widely known peripheral/configuration software | Medium — software class adjacency, famous mark |

Steam search also surfaces a developer named "Synapse Games." The field is crowded even before USPTO examination; an examiner or nDreams' counsel would have a straightforward likelihood-of-confusion case against a game titled "SYNAPSE."

## 2. Backup name results

| Candidate | Search result | Verdict |
|---|---|---|
| **Synaptic Hunters** | No game, product, or mark found | Clear in this search |
| **MUSE: Substrate** | No game or mark found (only a Muse-headband neurogame "Semse Planets", unrelated) | Clear in this search; note Muse® is a brain-sensing headband brand (InteraXon) — composite "MUSE: Substrate" in games likely distinguishable, flag for counsel |

## 3. What this does and does not mean

- It **does** mean the master plan's default (ship as "SYNAPSE") fails its own Task 0.4 validation; §14 decision 1 is now a live owner decision, not a default.
- It does **not** affect the codebase, repo name, or design documents — internal codenames carry no trademark exposure. All `docs/synapse/` materials remain valid; a title swap at marketing time is a find-replace in store copy.
- A professional clearance search (the IP consult) must still cover: USPTO TESS classes 9 + 41, EUIPO, common-law use, and the chosen final title.

## 4. Recommendation (owner decides; this is the studio's recommendation)

1. **Keep "SYNAPSE" as the internal codename** (repo, docs, builds) — zero exposure, zero churn.
2. **Ship under "MUSE: Substrate"** (first choice): unifies the product family with the M.U.S.E. platform brand, the post-game reveal lands harder ("the Substrate was a M.U.S.E. mind all along"), and the composite is distinctive. Verify the InteraXon Muse® adjacency with counsel.
3. **"Synaptic Hunters"** (second choice): clean and genre-legible, weaker brand tie.
4. Brief the $300 IP consult with this document; do not commission capsule art with a title lockup until the consult clears the chosen name (capsule composition work can start title-agnostic).
